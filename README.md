# OfferAgent · 面试刷题记忆工具

> 基于**艾宾浩斯遗忘曲线**的轻量化面试备考工具 —— 科学记忆、高效备考。

把零散的面试题，变成一套「新题学习 → 间隔复习 → 错题巩固 → 效果可视化」的完整备考闭环。

## ✨ 核心能力

- **结构化面试题库**：多分类（前端/后端/算法/数据库/网络/操作系统…），题目 + 解析 + 标签 + 难度。
- **智能记忆调度**：艾宾浩斯遗忘曲线（1/2/4/7/15/30 天间隔）+ 四级自评自适应调度。
- **卡片式刷题**：百词斩式卡片翻转，一次一题，秒级完成记忆决策。
- **多维数据追踪**：掌握度分布、每日学习曲线、分类进度、连续打卡，全程可视化。

## 🚀 快速开始

本项目为**纯静态、零构建、零依赖**的网页应用，本地数据存储在浏览器 `localStorage`。

### 方式一：直接打开

用浏览器直接打开 `index.html` 即可（无需服务器）。

### 方式二：本地预览服务

```bash
cd offeragent
python3 -m http.server 8000
# 打开 http://localhost:8000
```

### 方式三：部署到 GitHub Pages

仓库 Settings → Pages → 选择 `main` 分支根目录即可。

## 🧠 记忆调度模型

复习间隔阶梯（天）：`1 → 2 → 4 → 7 → 15 → 30`

四级自评驱动的自适应调度：

| 自评 | 阶段变化 | 间隔 | 难度系数 |
|------|----------|------|----------|
| 忘记 | 重置 | 回到 1 天 | -0.2 |
| 模糊 | -1 | 降级 | -0.15 |
| 记得 | +1 | 升级 | +0.05 |
| 牢记 | +2 | 跳级 | +0.10 |

> 实际间隔 = 阶段基准间隔 × 难度系数（ease）。
