# OfferAgent · 面试刷题记忆工具 —— 需求分析

> 版本：v1.0 ｜ 更新日期：2026-09-01

## 一、项目背景

求职者在面试备考过程中普遍面临四大痛点：

| 痛点 | 具体表现 | 后果 |
|------|----------|------|
| 知识点零散 | 面试题散落在博客、GitHub、公众号、视频中，无统一结构 | 难以系统复习，只见树木不见森林 |
| 刷题缺乏科学规划 | 大量刷题但从不复习，或凭感觉随机复习 | 会做的题反复做，不会的题没时间巩固 |
| 知识点遗忘率高 | 学过的题几天后遗忘，缺乏间隔复习机制 | 考前突击，长期留存率极低 |
| 备考效果无法量化 | 不知道学了多少、掌握多少、该复习什么 | 焦虑且无法针对性调整计划 |

## 二、产品定位

参考「百词斩」的单词记忆产品逻辑，开发一款**基于艾宾浩斯遗忘曲线的轻量化面试刷题记忆工具**。

- **核心主张**：科学记忆、高效备考
- **产品形态**：移动端优先的响应式网页 App（可运行于手机浏览器、微信内置浏览器）
- **使用场景**：利用通勤、排队等碎片化时间完成面试知识点的高效记忆与巩固

## 三、目标用户

- 正在准备技术岗位面试的在校生、应届生
- 寻求转岗 / 跳槽的在职工程师
- 需要系统复习基础知识（八股文、算法、项目经验）的求职者

## 四、核心目标（成功标准）

1. **结构化**：把零散面试题组织为分类清晰、标签化、带难度分级的题库。
2. **科学记忆**：基于艾宾浩斯遗忘曲线自动调度每道题的复习时间，实现「新题学习 → 间隔复习 → 错题巩固」。
3. **轻量易用**：卡片式刷题，一次只看一道题，自评掌握度，3 秒完成一次记忆决策。
4. **可量化**：用数据追踪学习效果（学习量、掌握度、遗忘率、连续打卡），让进步看得见。

## 五、功能范围（四大核心体系）

### 1. 结构化面试题库
- 多分类：前端 / 后端 / 算法 / 数据库 / 计算机网络 / 操作系统 等
- 每题包含：题目、答案解析、分类、标签、难度、来源
- 支持按分类 / 难度 / 掌握状态筛选浏览

### 2. 智能记忆调度（艾宾浩斯遗忘曲线）
- 复习间隔阶梯：1 天 → 2 天 → 4 天 → 7 天 → 15 天 → 30 天
- 四级自评驱动调度：忘记 / 模糊 / 记得 / 牢记
- 答对延长间隔、答错降级或重置，难度系数自适应调整
- 每日自动生成「待复习队列」与「新题学习队列」

### 3. 卡片式刷题
- 正面展示题目 → 点击翻转显示答案解析 → 自评掌握程度
- 支持「新题学习」「间隔复习」「错题巩固」三种模式
- 即时反馈与进度提示

### 4. 多维度学习数据追踪
- 总览：总题数 / 已学 / 已掌握 / 待复习 / 今日进度
- 每日学习曲线（近 14 天新增 + 复习量）
- 掌握度分布（新题 / 学习中 / 已掌握）
- 各分类学习进度
- 连续打卡天数、累计学习时长

## 六、备考闭环

```
新题学习 ──► 间隔复习 ──► 错题巩固 ──► 效果可视化
   │             │             │              │
   └── 记忆调度引擎（艾宾浩斯遗忘曲线）贯穿全程 ──┘
```

- **新题学习**：从未学题目中按日目标取新题，卡片学习并首次评分。
- **间隔复习**：到期题目进入今日队列，按遗忘曲线再次巩固。
- **错题巩固**：评分「忘记/模糊」的题自动降级，短期内反复出现直至掌握。
- **效果可视化**：图表呈现学习轨迹与掌握度变化，形成正向反馈。

## 七、非功能性需求

- **移动端优先**：响应式布局，适配 320px ~ 1440px 宽度，触控友好（≥44px 点击热区）。
- **离线可用**：纯静态 + localStorage 持久化，无网络也可刷题。
- **零依赖**：无构建步骤，无第三方 CDN，数据与图表全部本地实现。
- **数据可迁移**：支持学习数据导出 / 导入（JSON）。
- **无障碍**：尊重系统「减少动态效果」偏好，提供可见焦点态。

## 八、范围外（本期不做）

- 用户账号体系与云端同步（后续可扩展）
- 题目内容 UGC 社区 / 编辑器
- AI 出题、AI 面试陪练
- 付费 / 会员体系

## 九、风险与应对

| 风险 | 应对 |
|------|------|
| 题库内容质量与覆盖度 | 内置精选高频题，结构支持后续持续扩充 |
| localStorage 数据丢失 | 提供导出备份；后续接云端同步 |
| 遗忘曲线参数需贴合记忆规律 | 参数集中配置，可一键调优 |
