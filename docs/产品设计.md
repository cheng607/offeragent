# OfferAgent · 产品设计说明书

> 版本：v1.0 ｜ 更新日期：2026-09-01

## 一、信息架构

```
OfferAgent（单页应用，底部 4 Tab）
├── 首页    今日概览 / 学习入口 / 快捷统计
├── 刷题    卡片翻转刷题（新题 / 复习 / 错题）
├── 题库    结构化浏览 / 筛选 / 搜索
└── 统计    多维数据可视化
        └── 右上角「设置」：日目标 / 数据备份 / 关于
```

## 二、核心交互流程

### 2.1 刷题流程（记忆闭环）

```
进入刷题页
   │
   ├── 有待复习题？ ──是──► 进入「复习模式」
   │                         │
   ├── 否，有新题额度？ ──是──► 进入「新题学习」模式
   │
   └── 否 ──► 显示「今日任务完成」激励页
              │
  卡片正面（题目）
       │  点击「翻转」
  卡片背面（答案解析）
       │  四级自评
       ├── 忘记 ──► 重置记忆，短期再次出现
       ├── 模糊 ──► 降级间隔
       ├── 记得 ──► 升级间隔
       └── 牢记 ──► 跳级间隔
       │
  记录评分 → 调度下一题 → 循环
```

### 2.2 记忆调度规则（艾宾浩斯遗忘曲线）

**复习间隔阶梯（天）**：`[1, 2, 4, 7, 15, 30]`

| 自评 | 记忆阶段变化 | 间隔变化 | 难度系数 ease |
|------|--------------|----------|---------------|
| 忘记 | 重置到 0（立即重学） | 回到 1 天 | `max(1.3, ease-0.2)` |
| 模糊 | 阶段 -1（不低于 0） | 按降级后阶段 | `max(1.3, ease-0.15)` |
| 记得 | 阶段 +1 | 按升级后阶段 | `ease+0.05` |
| 牢记 | 阶段 +2（跳级） | 按升级后阶段 | `min(2.8, ease+0.1)` |

- 实际间隔 = 阶段基准间隔 × ease（自适应难度）
- 阶段达到 4 且连续答对 ≥ 2 次 → 判定「已掌握」
- 阶段回到 0 或评分「忘记」→ 进入「错题巩固」队列

## 三、页面设计

### 3.1 首页
- **顶部**：问候语 + 连续打卡天数徽章
- **今日任务卡**：待复习 N 题 / 新题 M 题，一键「开始学习」
- **进度环**：今日完成度
- **快捷统计**：已学 / 已掌握 / 累计复习 四项卡片
- **最近分类进度**：横向条形

### 3.2 刷题页
- **模式标识**：新题学习 / 间隔复习 / 错题巩固
- **进度条**：今日第 x / y 题
- **卡片**：正面题目（大字号，可滚动），点击翻转
- **背面**：答案解析 + 标签 + 分类
- **自评按钮组**：忘记 / 模糊 / 记得 / 牢记（不同颜色）
- **空状态**：今日任务完成激励

### 3.3 题库页
- 顶部分类 Tab（横向滚动）
- 题目列表：题号、题干摘要、难度星标、掌握状态徽章
- 点击展开查看完整答案
- 搜索框按关键词过滤

### 3.4 统计页
- 掌握度分布环形图
- 每日学习曲线（近 14 天柱状 + 折线）
- 分类学习进度横向条形
- 记忆留存率曲线（理论遗忘曲线叠加实际留存）

### 3.5 设置
- 每日新题目标 / 复习目标（可调）
- 数据导出（下载 JSON）/ 导入
- 清空学习数据（二次确认）
- 关于 / 版本信息

## 四、视觉规范

| 维度 | 规范 |
|------|------|
| 主色 | 珊瑚红 `#E4573D`（唯一强调色，饱和度 < 80%） |
| 背景 | 暖米白 `#F7F5F0` |
| 卡片 | 纯白 `#FFFFFF`，柔和投影 |
| 正文 | 暖黑 `#211F1C`（避免纯黑 #000） |
| 辅助 | 灰 `#8A867E` |
| 功能色 | 掌握·绿 `#3E9B6F` ｜ 模糊·琥珀 `#E0A22E` ｜ 忘记·红 `#C9473B` |
| 字体 | 系统无衬线（PingFang SC / Microsoft YaHei / system-ui），标题加粗、正文适中 |
| 圆角 | 卡片 20px，按钮 12px，胶囊 999px |
| 图标 | 内联 SVG（全站不使用 emoji） |
| 动效 | 卡片 3D 翻转、按钮按压缩放、页面淡入，尊重 `prefers-reduced-motion` |

## 五、状态与反馈设计

- **加载态**：首页数据加载骨架
- **空态**：题库为空 / 今日任务完成 / 无数据图表占位
- **错误态**：数据导入失败 / 存储异常提示
- **触觉反馈**：按钮按下 `scale(0.98)`，卡片翻转弹簧缓动
