### 关键问题与解决

#### 问题 1：底部导航在 390px 视口下只显示 3 个 tab

**现象**：无头 Chrome 截图中底部只显示「首页 / 刷题 / 题库」，缺少「统计」。

**排查**：
- 检查 DOM，确认 4 个 `<button class="tab">` 均存在。
- 通过注入临时脚本打印 `window.innerWidth` 与 `getBoundingClientRect()`，发现无头 Chrome 实际视口为 500px，而截图文件宽度为 390px。tabbar 按 `max-width: 480px` 渲染，因此截图只能看到左侧 390px 内容，造成「缺少第 4 个 tab」的假象。
- 在 480px 宽度截图下，4 个 tab 完整显示。

**解决**：
- 将 tabbar 从 `display: flex` 改为 `display: grid; grid-template-columns: repeat(4, minmax(0, 1fr))`，确保无论内容宽度如何，4 个 tab 始终等分容器。
- 为 `.tab` 增加 `min-width: 0` 与 `overflow: hidden`，防止内容撑开网格列。
- 将 SVG 图标与文字适当缩小（20px / 10px），提升极小屏幕下的容纳能力。

**结论**：UI 布局本身正确；无头截图的视口不一致是测试环境 artifact。真实移动设备上 4 个 tab 会正常显示。

#### 问题 2：图表 SVG 路径拼接错误

**现象**：`js/charts.js` 中折线图的 `<path>` 标签嵌套错误。

**解决**：重构 `renderRetentionCurve`，使用独立的 `path()` 函数生成 `d` 属性，再拼接到 `<path d="...">` 中，避免标签嵌套。
